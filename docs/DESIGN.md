# Keylane 产品与实现设计

## 最终任务边界

用户修正：“不要保存，仅是获取验证码，以及生成 2fa 密钥啥的”。因此本版本是临时计算工具，不是认证服务器或密钥管理器。无注册、登录、账户列表、数据库、备份、浏览器持久化、云同步、PWA / Service Worker。所有输入仅存在当前页面内存；复制到系统剪贴板必须由用户点击。

## 视觉设计

颜色：浅雾背景 `#f5f7f8`、白色工作面 `#ffffff`、文字 `#263b35`、松绿色操作 `#146b5a`、深绿验证码面板 `#123f36`、浅绿选中态 `#e9f3ee`。

字体：系统 Segoe UI / 微软雅黑用于标题与中文；Consolas / Cascadia Code 用于验证码与密钥。使用系统字体以避免外部字体请求。布局左对齐，验证码居中，以深绿输出区突出唯一最重要的数据。

```
侧栏工具导航 | 面包屑                         本地计算 / 主题
             | 标题与“会清空”提示
             | 密钥输入 + 参数    | 大号验证码 + 倒计时 + 复制
             | 三步说明 / 时间异常提示
```

设计复核：初期账户卡片/保险库构想不适合最终需求，已改为输入/输出两区；不显示虚构账户或指标，不添加首页营销大图，默认不放任何真实/示例密钥。较窄屏幕改为单列，手机顶部为工具导航。

## 功能与验收

| 功能 | 行为 | 验收重点 |
|---|---|---|
| 单条取码 | 粘贴后 350ms 防抖计算，也支持提交按钮 | 输入修改立即禁用旧结果复制；自动更新 |
| 配置链接 | 解析 issuer/account/type/algorithm/digits/period/counter | URI 参数优先，重复参数/冲突 issuer 拒绝 |
| TOTP | SHA-1/256/512，6/8 位，5–300 秒周期 | RFC 6238 18 个向量；30/60 秒边界 |
| HOTP | 非负安全整数计数器，手动递增 | RFC 4226 10 个向量；复制不递增 |
| 随机密钥 | CSPRNG 160/256/512 bit，Base32 | 字节长度与编码往返；不使用 Math.random |
| 配置生成 | 服务、账户、参数 → 密钥、URI、二维码 | 三者一致；提示先完成服务端绑定 |
| QR 识别 | 文件、拖放、粘贴，jsQR 本地解码 | 最大 5 MB，PNG/JPEG/WebP，标准 otpauth |
| 批量取码 | 最多 50 行，逐行错误，不回显秘密 | 有效条目独立刷新和复制 |
| 清空 | 手动、换工具、刷新、pagehide | 输入与生成结果清空，过期异步任务不能恢复数据 |

## 数据流

```
输入 / 图片 → 本地校验 → 标准 OTP 参数 → Web Crypto HMAC → 验证码 DOM
随机字节 → Base32 密钥 → otpauth URI → 本地 QR 编码 → Canvas
                                              ↓ 用户点击
                                         系统剪贴板
```

没有服务器 API。`src/otp.js` 是可独立测试的算法与解析模块；`src/app.js` 管理短期状态和视图；`scripts/serve.mjs` 只提供 dist 静态文件，不记录请求日志。`epoch` 在清空和输入变化时递增，异步计算只有版本一致才能更新界面。验证码复制时重新按当前时刻计算，降低跨周期复制旧码的风险。

## 安全和兼容性边界

- 主密码与加密保险库代码已经移除，不用“不保存”包装其他形式的持久化。
- 默认掩码显示输入；批量输入为可见文本，适合已知安全的环境。
- CSP 限制脚本仅同源，生产服务禁止 connect 请求，禁用嵌入、表单提交、相机等无关权限。生产资源 `Cache-Control: no-store`。
- 二维码、链接、密钥等价敏感，不提供“密钥放入 URL 自动取码”的功能，避免浏览历史、Referer 和服务端日志泄漏。
- 不支持 Steam、Google `otpauth-migration://` 批量迁移、恢复码、短信或推送验证。HOTP 上限为 JavaScript 最大安全整数，不声称支持全 64 位计数器空间。
- Base32 要求至少 16 字符，拒绝错误填充和非零尾部位。可接受较常见的短种子，但新密钥至少生成 160 bit。
- 设备时钟影响 TOTP，不访问外部时间 API。页面加载后计算可离线；无 Service Worker，所以不承诺断网冷启动。
- 浏览器扩展、系统剪贴板、内存转储、恶意同源脚本、托管服务器被篡改都超出页面清空能防御的范围。JavaScript 清空引用不等于物理内存安全擦除。
- 图片解码在主线程，较大图片会短暂占用页面；先限制文件体积，解码后限制像素量并缩小至最长边 1600px。像素限制不能避免浏览器初次解码的大图内存分配，后续可移入 Worker。
